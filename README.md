# subdeck-privacy

Subdeck 隐私政策和支持页面的 GitHub Pages 静态网页仓库。本仓库只用于发布 Privacy Policy 和 Support URL，不是 App 源代码仓库。

## 隐私政策

打开 `index.html` 即可查看。页面顶部可用 **中文 | English** 切换语言，中英文隐私政策正文已按正式法律文案原样放入。

发布后访问地址：

https://qihu87.github.io/subdeck-privacy/

## 支持页面

打开 `support/index.html` 即可查看。页面风格与隐私政策页一致，同样可用 **中文 | English** 切换语言。

该页面供 App Store Connect 的 Support URL 使用，内容包括联系方式、恢复购买、年度订阅、终身购买、iCloud 同步、通知提醒、退款说明，以及隐私政策和 Apple 标准 EULA 链接。

发布后访问地址：

https://qihu87.github.io/subdeck-privacy/support/

## 说明

页面不加载任何第三方脚本、字体、Analytics 或 Cookie。
